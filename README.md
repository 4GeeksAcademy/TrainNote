# TrainNote

A web application for logging workouts, nutrition, and body weight, and for tracking a person's fitness progress. It also allows for the generation of personalized training or nutrition plans using artificial intelligence.

## Description

TrainNote is a platform where users can create an account and manage their fitness information in one place.

Users can log their daily workouts, including exercises, sets, repetitions, weight used, and duration.

They can also log meals—tracking calories, protein, carbohydrates, and fats—as well as monitor their body weight.

The application uses the logged data to display user progress through statistics and charts.

TrainNote also enables the generation of personalized plans using artificial intelligence. Users can choose between a training plan or a nutrition plan and provide the necessary details to receive a recommendation tailored to their goals.

## Features

- User registration.
- Login.
- JWT-based authentication.
- Password recovery.
- Profile viewing and updating.
- Workout logging.
- Logging of exercises, sets, repetitions, and weight used.
- Meal logging.
- Body weight logging.
- Progress tracking.
- Weight progression charts.
- Log history viewing.
- AI-generated training plans.
- AI-generated nutrition plans.
